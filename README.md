# ProjectOnBoarding

Internal web application for Laine's user access management: onboarding, offboarding, and access modification requests, with approvals, IT execution tracking, sign-off, PDF export, reports, and an AI-assisted data-entry panel.

**Status:** planning. No application code yet.

- [Project plan](PROJECT_PLAN.md): scope, stack, workflow, data model, delivery phases, and open decisions.

Planned stack: Next.js 16 (App Router, TypeScript), Clerk, Supabase (Postgres + Storage), Vercel, Vercel AI SDK.
